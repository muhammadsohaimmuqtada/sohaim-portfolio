# sohaim-portfolio

Personal cybersecurity portfolio for Sohaim Muqtada.

## Design principles

- restrained editorial layout rather than dashboard/card overload
- real project links and concise copy
- interactive portrait reveal, project hover depth, scroll reveals and responsive navigation
- no runtime dependencies or client framework overhead
- accessibility and reduced-motion support

## Run locally

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Deploy

The site is Vercel-compatible as a static project.
